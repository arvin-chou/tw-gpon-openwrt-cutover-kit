# Security policy

Do not open an issue containing GPON identity, PLOAM, PPPoE credentials, Wi-Fi
keys, MAC addresses, public IP addresses, SSH private keys, Router backups, or
raw state files. Redact subscriber data before sharing logs.

The package intentionally does not provision ONU identity. A profile is a
tested hardware/ISP contract, not a suggestion to bypass provider controls.
Report safety bugs through [GitHub private vulnerability reporting](https://github.com/arvin-chou/tw-gpon-openwrt-cutover-kit/security/advisories/new).
Do not open a public issue for a suspected credential leak or safety flaw.
